# Glassing terrain experiment

A small runnable terrain-visibility baseline, with an offline synthetic example
and a 64 km² Colorado GMU 54 pilot. It does not predict deer or certify legal access.

Start with [run instructions](docs/glassing/README.md),
[numerical evidence](docs/glassing/NUMERICAL_EVIDENCE.md) and
[execution status](docs/glassing/STATUS.md).
The supplied methodology report remains an unvalidated planning hypothesis.

The separate matched habitat/glassability experiment is now runnable. See its
[comparison report](docs/glassing/comparison/REPORT.md) and
[commands](docs/glassing/comparison/README.md). It preserves the terrain control
and provides blank blinded review sheets; no scouting improvement is claimed.
